# Telegram AI Bot — открытый стартовый набор

Самостоятельно разворачиваемый Telegram-бот для личных чатов и групп. Нужны **ваши** токен Telegram и ключ любого AI-провайдера — проект не поставляет ключи и не является хостингом. Поддерживаются Gemini и совместимые с OpenAI Chat Completions API провайдеры: OpenAI, OpenRouter, Groq, Together и совместимые шлюзы. Хранение — SQLite, отдельная база данных не нужна.

- Python 3.10+
- Google Gemini Developer API (`google-genai`)
- Лицензия MIT: [`LICENSE`](LICENSE)

## Самый простой запуск: Docker Compose

1. Установите Docker Engine и Compose.
2. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
3. Выберите провайдера. Для Gemini создайте ключ в [Google AI Studio](https://aistudio.google.com/apikey); для OpenAI-совместимого API возьмите ключ, базовый URL и ID модели из документации провайдера.
4. В папке репозитория:

   ```sh
   cp .env.example .env
   ```

   Впишите `TELEGRAM_BOT_TOKEN` и выберите провайдера. Для Gemini укажите `AI_PROVIDER=gemini` и `GEMINI_API_KEY`; для OpenAI-совместимого API — `AI_PROVIDER=openai-compatible`, `AI_API_KEY`, `OPENAI_COMPAT_BASE_URL`, `OPENAI_COMPAT_MODEL`. `.env` игнорируется Git — не отправляйте его в публичный репозиторий.
5. Запустите:

   ```sh
   docker compose up -d --build
   docker compose logs -f bot
   ```

   База хранится в именованном Docker volume (`tg-ai-bot_bot_data` по умолчанию). Остановка: `docker compose down` (volume сохраняется); обновление: `git pull && docker compose up -d --build`. Не используйте `down -v`, если не хотите удалить базу. Команды управления в Docker запускайте внутри того же контейнера, чтобы использовать его SQLite: `docker compose exec bot python manage.py status`; для интерактивной команды используйте `-it`.

## Запуск без Docker (Windows, macOS, Linux)

Установите Python 3.10+ и Git, склонируйте проект и перейдите в его папку.

```sh
python manage.py setup
```

Мастер предложит выбрать Gemini или OpenAI-совместимый API, запросит Telegram-токен и ключи без отображения ввода и создаст `.env`. Затем проверьте доступ и запустите:

```sh
./botctl check --live   # macOS/Linux; на Windows: python manage.py check --live
./botctl start          # запуск в foreground; остановка Ctrl+C
```

В Windows можно запустить `start_bot.ps1`: он создаст виртуальное окружение `.venv`, установит зависимости, предложит настроить `.env`, проверит параметры и запустит бота. Для постоянной работы сервера предпочтительны Docker Compose или systemd.

## Подключение к группе

Добавьте бота в группу. Чтобы он получал обычную переписку для контекста, в BotFather выполните `/setprivacy` → выберите бота → **Disable**. Если Telegram попросит, удалите бота из группы и добавьте снова. Сообщите участникам, что бот сохраняет получаемые сообщения для контекста; получите согласие, если оно требуется для вашего сценария. При включённом Privacy Mode Telegram будет передавать боту только разрешённые обновления, и контекст группы будет неполным.

В группах бот отвечает на своё упоминание, на `@ai` (настраивается `TRIGGER_MENTION`) или на ответ на его сообщение. Голосовое обрабатывается только когда адресовано боту упоминанием/ответом. Боту может потребоваться статус администратора, чтобы Telegram позволил проверять права администраторов группы.

## Настройки и ограничения

Параметры находятся в `.env`; пояснения и значения по умолчанию — в `.env.example`.

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `AI_PROVIDER` | `gemini` | `gemini` или `openai-compatible` |
| `AI_API_KEY` | пусто | Ключ OpenAI-совместимого API |
| `OPENAI_COMPAT_BASE_URL` | OpenAI API URL | URL API провайдера с путём `/v1` |
| `OPENAI_COMPAT_MODEL` | пусто | ID модели для совместимого API |
| `GEMINI_MODEL` | `auto` | В автоматическом режиме используются экономичные Flash-Lite модели |
| `GEMINI_API_KEYS` | пусто | Необязательные ключи через пробел/запятую; также поддерживается `GEMINI_API_KEY` |
| `PRIVATE_DAILY_TOKEN_LIMIT` | 40 000 | Дневная квота личного чата на пользователя |
| `GROUP_DAILY_TOKEN_LIMIT` | 150 000 | Общая дневная квота группы; пополнить её нельзя |
| `GLOBAL_DAILY_TOKEN_LIMIT` | 500 000 | Общий дневной защитный предел бота |
| `STAR_TOKEN_PACKS` | пусто | Необязательные пакеты `ТОКЕНЫ:STARS`, например `100000:50,500000:200` |
| `MEMORY_RETENTION_DAYS` | 30 | Срок хранения переписки и явно сохранённых фактов |
| `MAX_DATABASE_MB` | 500 | Порог автоматического уплотнения SQLite |
| `MAX_VOICE_SECONDS` | 120 | Максимальная длительность голосового |
| `GEMINI_TRANSCRIPTION_MODEL` | `gemini-2.5-flash-lite` | Модель транскрибации адресованных голосовых |
| `SQLITE_PATH` | `bot_memory.sqlite3` | Путь к SQLite |

Это **ограничения приложения**, а не обещание бесплатной квоты Google. Лимиты Gemini зависят от проекта и модели; ключи внутри одного проекта делят общую квоту. Автоматический выбор Gemini специально ограничен экономичными Flash-Lite моделями. Не задавайте модели в `GEMINI_FALLBACK_MODELS`, пока не проверили цену и доступность. Для других провайдеров тарифы и лимиты определяет сам провайдер. Google может менять модели и бесплатный доступ.

Фактические токены ответа Gemini записываются, когда API возвращает метаданные; в остальных случаях расход оценивается приблизительно. `/usage` показывает примерные слова и обмены сообщениями, но контекст влияет на расход. Дневные лимиты приложения сбрасываются в 00:00 UTC. Распознавание в Gemini расходует его квоту; для OpenAI-совместимых API провайдер должен поддерживать endpoint `/audio/transcriptions`, иначе задайте пустой `TRANSCRIPTION_MODEL`, чтобы отключить голосовые.

### Оплата Stars (по желанию)

Оплата отключена, пока владелец инсталляции явно не задаст `STAR_TOKEN_PACKS`. Формат — количество токенов, затем цена в Stars: `STAR_TOKEN_PACKS=100000:50,500000:200`. Цены выбирает владелец бота. `/buy` покажет список пакетов, `/buy 1` выставит счёт только на первый пакет. После подтверждения оплаты Telegram баланс начисляется один раз. Пакеты пополняют баланс пользователя в личке; групповую квоту купить или пополнить нельзя. Перед запуском реальных продаж проверьте цены, условия, поддержку/возвраты и работу на тестовом боте.

## Команды бота

- `/start` — инструкции
- `/status` — параметры памяти и модели
- `/usage` — остаток квоты, приблизительная оценка и платный баланс
- `/buy` — список пакетов Stars; `/buy 1` — покупка первого
- `/remember <факт>` — явно сохранить факт на срок хранения
- `/forget` — удалить сохранённые факты (в группе — администратору)
- `/reset` — очистить историю и факты (в группе — администратору)

## Управление и обслуживание

```sh
./botctl                 # интерактивное меню (macOS/Linux)
python manage.py         # меню на любой платформе
python manage.py check   # локальная проверка конфигурации и SQLite
python manage.py check --live  # дополнительно проверяет Telegram и выбранного AI-провайдера
python manage.py status
python manage.py disable # выключить ответы и разослать уведомление
python manage.py enable  # включить ответы и разослать уведомление
python manage.py vacuum  # удалить просроченное и уплотнить базу
python manage.py clear-memory # необратимо очистить историю/факты всех чатов
```

Очистка просроченных данных выполняется каждый час, пока бот работает. Если база достигла `MAX_DATABASE_MB`, она уплотняется; команду `vacuum` можно запускать вручную. При Docker/systemd останавливайте процесс через `docker compose down` или systemd, чтобы менеджер процессов не запустил бота повторно. Например, в Compose: `docker compose exec -it bot python manage.py vacuum`.

## Приватность и безопасность

Оператор сам отвечает за ключи, доступ к серверу, квоты/биллинг провайдера и уведомление пользователей. Получаемая ботом групповая переписка и факты хранятся локально в SQLite на заданный срок. Сообщения, используемые в запросе, и адресованные голосовые передаются выбранному AI-провайдеру; проверьте его условия обработки данных. Никогда не коммитьте `.env`, API-ключи, Telegram-токен или SQLite-файл.

Это стартовый набор с открытым исходным кодом, а не размещённая служба с гарантией доступности. См. [безопасность](SECURITY.md), [вклад в проект](CONTRIBUTING.md) и [лицензию](LICENSE).
